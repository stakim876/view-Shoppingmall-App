# My Shop

포트폴리오 + 실습용으로 만든 쇼핑몰 데모입니다.  
처음부터 완성도 높은 서비스 만들기보다, 실제 쇼핑 흐름(상품 보기 → 장바구니 → 결제 → 주문 확인)이 끊기지 않게 만드는 걸 목표로 했습니다.

프론트는 Vue3 + Vite, 상태관리는 Pinia, 라우팅은 Vue Router, 스타일은 Tailwind로 작업했습니다.  
백엔드는 Express + MySQL이고, 인증은 JWT 방식입니다.

---

## 배포 관련

프론트는 Vercel에 올려서 확인했고, 백엔드는 Render/Railway 쪽으로 붙여보면서 배포 과정도 같이 연습했습니다.

배포하면서 제일 크게 막힌 건 DB 연결이었습니다.  
로컬에서는 `localhost`로 잘 됐는데, 배포 서버에서는 당연히 안 붙어서(서버 기준 localhost라서) 외부 DB 정보가 필요하다는 걸 그때 정확히 이해했습니다.

솔직히 이 부분에서 제일 많이 헤맸습니다.

---

## 구현하면서 바꾼 것들

### 1) 주문 금액 검증
초반엔 프론트에서 보내준 `total_price`를 그대로 받았는데,  
요청값 바꿔서 보내면 위험하겠다는 생각이 들어서 서버에서 다시 계산하게 바꿨습니다.

지금은 서버 계산값이랑 다르면 주문 거절합니다.

### 2) 인증 에러 공통 처리
로그인 만료나 토큰 문제(401/403)가 여러 화면에서 반복돼서,  
`client/src/lib/api.js` 인터셉터에서 공통 처리하게 정리했습니다.

각 페이지마다 중복으로 처리하던 코드 줄어들어서 유지보수가 훨씬 편해졌습니다.

### 3) 스키마 차이 대응
로컬 DB랑 다른 환경 DB 컬럼이 완전히 같지 않아서 실제로 에러가 났습니다.  
그래서 일부 컬럼(`imp_uid`, `merchant_uid`)은 있을 때만 저장하게 처리했습니다.

테이블이 없는 경우도 전체가 다 죽지 않게, 해당 기능만 안내/빈값으로 넘기는 식으로 방어 코드 넣었습니다.

## 구조 (현재)

현재 백엔드 진입은 `backend/server.js` 하나입니다.  
처음엔 빨리 붙이기 좋아서 이렇게 갔는데, 기능 많아지니까 파일이 커져서 보는 게 힘들어졌습니다.

그래서 공통 로직은 `backend/lib`로 계속 빼는 중입니다.

- `auth.js`: JWT, 비밀번호
- `coupon.js`: 쿠폰 검증
- `productQuery.js`: 상품 목록 쿼리
- `loginSecurity.js`: 로그인 시도 제한
- `captcha.js`: 캡차
- `mailer.js`: 메일
- `tracking.js`: 배송조회 URL

다음 단계 목표는 라우트도 도메인별로 분리하는 겁니다.

## 주요 기능

- 회원가입 / 로그인
- 상품 목록 / 상세 / 카테고리
- 장바구니 / 찜
- 쿠폰 검증
- 주문 생성 / 주문 조회
- 관리자 주문 상태 변경 / 송장 등록
- 공지 관리
- 리뷰 / 재입고 알림
- 챗봇 API(백엔드에서 OpenAI 호출)
