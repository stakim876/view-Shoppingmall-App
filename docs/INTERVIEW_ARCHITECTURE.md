# 면접용 — 한 페이지

## 기업이 보는 3가지

1. **끝까지 되나** — 홈 → 상품 → 장바구니 → 결제
2. **믿을 수 있나** — 서버 금액 재계산, 재고 트랜잭션, 로그인·권한
3. **운영 되나** — Admin 상품·주문·공지

AI·CRM·시니어 UI 같은 건 **의도적으로 빼고** 위 3가지에 맞췄습니다.

---

## 구조

| 화면 | 역할 |
|------|------|
| `/home` | 베스트·신상·카테고리 |
| `/products` | 전체 목록·검색·필터 |
| `/checkout` | 로그인 필요, 서버 금액 검증 |
| `/admin` | 상품·주문·공지 |
